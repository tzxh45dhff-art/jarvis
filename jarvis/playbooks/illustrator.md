# Adobe Illustrator (vector graphics)

- Layout: Tools panel on the left, Control bar across the top (context
  options), Properties/Layers/Libraries panels on the right. Artboards are the
  white pages; Window menu shows/hides every panel.
- Selection: `V` Selection tool, `A` Direct Selection (edit points), `P` Pen,
  `T` Type, `M` Rectangle, `L` Ellipse, `Shift+X` swap fill/stroke.
- Common: group `Cmd+G`; align via Properties > Align; Pathfinder (Window >
  Pathfinder) unite/minus-front/intersect; Object > Expand to outline a stroke;
  Type > Create Outlines before sending to print.
- Export: File > Export > Export As (PNG/JPG/SVG) or Export for Screens
  (`Option+Cmd+E`) for several sizes; Save for web is under File > Export.
- If a panel is missing: Window > Workspace > Reset Essentials.
Use show_steps with visible menu/panel names; Illustrator's own scripting is
not available to JARVIS, so coach rather than automate.
