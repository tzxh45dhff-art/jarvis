# iMovie

- Library (left), Browser (top-middle), Viewer (top-right), Timeline
  (bottom). Create: Movie > Create New (or the + button).
- Add clips: drag from the Browser to the Timeline; split at the playhead
  with `Cmd+B`; trim by dragging the edges; speed via the Speed button above
  the viewer.
- Titles, backgrounds, transitions: the tabs above the Browser.
- Export: Share button (top right) > File, or File > Share > File.
- For quick file-level edits without opening iMovie, video_tool can trim,
  join, speed up, crop to vertical and compress exported files.
