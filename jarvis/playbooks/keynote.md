# Keynote (and PowerPoint)

For *making* a deck, prefer make_presentation (creates a designed .pptx that
opens in Keynote or PowerPoint) and edit_presentation, then open_file to show
it. Use the on-screen route only to teach or when the user is mid-edit.

## Keynote layout
- Slide navigator on the left; slide canvas in the middle; **Format** sidebar
  on the right (Style / Text / Arrange tabs change with the selection);
  **Animate** and **Document** buttons at the top right.
- Toolbar (top): View, Zoom, Add Slide, Play, Table, Chart, Text, Shape, Media,
  Comment, Share, Format, Animate, Document.
- New slide: Slide > New Slide, or the toolbar "Add Slide" (change its layout
  with the slide's master via Format > Slide > Change Master).
- Present: Play > Play Slideshow (`Option+Cmd+P`); Esc to exit.
- Transitions and builds: select slide(s) > Animate > Add an Effect; text and
  objects animate via Animate > Build In / Build Out.
- Export: File > Export To > PDF / PowerPoint / Movie / Images.
- Speaker notes: View > Show Presenter Notes.

## PowerPoint
- Ribbon tabs: Home, Insert, Design, Transitions, Animations, Slide Show,
  Review, View. New slide: Home > New Slide. Present: Slide Show > From
  Beginning (`Cmd+Return`). Export PDF: File > Export.
- Designer ideas: Design > Designer. Layout: Home > Layout.

## Good-deck coaching
One idea per slide; five short bullets at most; large type (24 pt+); a
picture or chart beats a paragraph; end with the one action you want.
